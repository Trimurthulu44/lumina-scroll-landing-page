# 🚀 Engineered Lumina: A Production-Ready Scroll-Based Landing Page in React 18 & Framer Motion

I just wrapped up building **Lumina** — a production-grade, scroll-orchestrated digital product studio landing page built with modern frontend engineering principles.

### 💡 What I Built:
- **14 Advanced Scroll & Motion Features**: A fluid sticky glassmorphism navbar with active link tracking, multi-layer parallax hero, interactive 3D tilt cards with cursor glow, scroll-drawn milestone timeline, draggable testimonial carousel, and animated counters.
- **Robust Custom Form System**: Engineered a dependency-free `useForm` hook with real-time validation, accessible ARIA attributes, async state handling, and toast alerts.
- **Zero-FOUC Dark/Light Theming**: Synchronous HTML script prevents white flashes on reload, coupled with an animated sun/moon toggle.
- **Performance & Accessibility First**: Integrated Lenis smooth scrolling with prefers-reduced-motion support, code splitting via React.lazy/Suspense, and full WCAG AA compliance.

### 🛠️ Tech Stack:
React 18 · Tailwind CSS v3.4 · Framer Motion · Lenis · Vite · lucide-react
